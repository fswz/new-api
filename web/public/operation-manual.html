创建 API 密钥

API 密钥是应用调用 LeYao API 的凭证。它与登录密码不同，可以独立禁用、限制额度和设置过期时间。

创建步骤

注册并登录

打开 LeYao API 注册页 创建账号，完成登录后进入控制台。

进入 API 密钥页面

在左侧导航选择“API 密钥”，或直接打开 https://api.leyao.fswz.cc/keys。

创建密钥

点击“创建 API 密钥”，名称建议写设备或用途，例如 codex-windows、office-codex。

设置分组和额度

选择可用分组；需要控制风险时，为密钥设置额度、过期时间和允许访问的模型。

保存并复制

保存后复制以 sk- 开头的密钥。密钥只应存放在本机安全配置或可信的密钥管理器中。

你需要记住的信息

信息填写内容
OpenAI 兼容 Base URL https://api.leyao.fswz.cc/v1
API Keysk-xxxxxxxxxxxxxxxx
推荐测试模型gpt-5.4-mini
高能力模型gpt-5.6-sol
密钥泄露怎么办？ 立即在“API 密钥”页面禁用或删除旧密钥，再创建新密钥。不要只修改本机配置后继续保留泄露的密钥。

安装 CC Switch

CC Switch 是跨平台配置管理工具，可集中管理 Codex 等 AI 编程工具的 Provider、Base URL、API Key 和模型映射。 不使用 CC Switch 也可以跳到“手动配置 Codex”。

打开 CC Switch 下载页 跳过 CC Switch

Windows

从 Release 页面下载 Windows 安装包，完成安装后启动 CC Switch。若系统弹出安全提示，请确认下载来源后再继续。

macOS

下载与你芯片架构匹配的安装包。Apple Silicon 选择 arm64，Intel Mac 选择 x64；首次打开时按系统提示授权。

Linux / WSL

环境安装方式
Ubuntu / Debian下载 .deb 包后执行 sudo dpkg -i cc-switch-*.deb
Fedora / RHEL下载 .rpm 包后执行 sudo rpm -i cc-switch-*.rpm
Arch Linux使用 AUR 安装 paru -S cc-switch-bin
通用 Linux下载 AppImage，赋予执行权限后运行
WSL建议在 Windows 侧运行 CC Switch，在 WSL 中使用 Codex CLI

验证 CC Switch

启动后应能打开 Provider 列表，并识别本机已安装的 Codex。若未识别，可先完成下一节的 Codex 安装，再重新启动 CC Switch。

安装应用

安装 Codex

Codex 有桌面应用和命令行两种使用方式。只使用桌面应用时，无需安装 Node.js。

Codex App

前往 OpenAI Codex 官方页面 下载应用。Windows 也可从 Microsoft Store 安装。

Codex CLI

先安装 Node.js LTS，然后在终端执行：

终端
npm install -g @openai/codex
codex --version

配置 API 密钥

完成应用安装后，将创建的 API 密钥和本站 Base URL 配置到 CC Switch 或 Codex 中。

通过 CC Switch 配置（推荐）

LeYao API 的 API 密钥页面提供 CC Switch 配置入口；若系统没有自动唤起应用，可以使用后面的手动添加方法。

从 API 密钥页面导入

打开 API 密钥页面

登录控制台，进入“API 密钥”，找到准备在本机使用的密钥。

选择 CC Switch

打开密钥右侧菜单，选择 CC Switch 配置入口。

确认系统唤起

浏览器会请求打开 CC Switch。确认后检查 Provider 名称、Base URL 和目标应用。

选择模型

主力模型可选择 gpt-5.6-sol；低成本或连通性测试可选择 gpt-5.4-mini。

保存并启用

保存 Provider，在 CC Switch 中将其设为当前配置，然后重启 Codex。

手动配置 Codex（不使用 CC Switch）

不使用配置管理工具时，可以设置环境变量并编辑 Codex 配置文件。

PowerShell
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-xxxxxxxxxxxxxxxx", "User")
[Environment]::SetEnvironmentVariable("OPENAI_BASE_URL", "https://api.leyao.fswz.cc/v1", "User")

设置完成后关闭并重新打开终端，让用户级环境变量生效。

bash / zsh
export OPENAI_API_KEY="sk-xxxxxxxxxxxxxxxx"
export OPENAI_BASE_URL="https://api.leyao.fswz.cc/v1"
重新加载 shell
source ~/.bashrc
# 使用 zsh 时执行：source ~/.zshrc

编辑 Codex 配置文件

配置文件通常位于 ~/.codex/config.toml。Windows 用户可在用户目录下的 .codex 文件夹中找到它。

config.toml
model = "gpt-5.6-sol"
model_provider = "leyao"

[model_providers.leyao]
name = "LeYao API"
base_url = "https://api.leyao.fswz.cc/v1"
wire_api = "responses"
env_key = "OPENAI_API_KEY"
env_key 填变量名 env_key 应填写 OPENAI_API_KEY，不要把真实密钥直接写进 config.toml。

验证配置

重新打开终端后运行：

终端
codex "请用一句话说明当前连接是否正常"

能够正常返回内容即表示配置成功。也可以先在 LeYao API 控制台的“游乐场”中测试账号和模型权限。

常见问题

提示 401 或 API Key 无效怎么办？

确认密钥没有多余空格、没有被禁用或过期，并检查应用读取的是当前终端中的 OPENAI_API_KEY。密钥泄露时应直接作废并重新创建。

提示 404 或无法找到接口怎么办？

Codex 使用的 Base URL 应为 https://api.leyao.fswz.cc/v1。漏掉 /v1、重复添加 /v1，或把模型名称写错，都可能导致请求失败。

提示模型不存在或无权访问怎么办？

在模型广场确认模型名称，并检查 API 密钥所属分组是否包含该模型。修改分组后，重新启动应用或新建会话再测试。

CC Switch 已保存，但 Codex 仍使用旧配置怎么办？

确认已启用正确的 Provider，完全退出并重新打开 Codex；终端用户还应关闭旧终端窗口，避免旧环境变量继续生效。

连接超时或响应很慢怎么办？

先访问 LeYao API 控制台确认网络可达，再检查本机代理、DNS 和防火墙。代理软件开启时，可尝试将 api.leyao.fswz.cc 加入直连规则。

如何控制单个设备的用量？

为每台设备分别创建 API 密钥，并设置独立名称、额度和过期时间。这样可以单独查看日志，也能在设备丢失时只撤销对应密钥。

安全建议

  • 不同设备和用途使用不同 API 密钥，避免多人共用一个密钥。
  • 为测试环境设置较小额度和有效期，生产用途再单独创建密钥。
  • 不要在截图、群聊、工单、代码仓库和 shell 历史中暴露完整密钥。
  • 定期检查使用日志，发现异常模型、IP 或用量时立即撤销密钥。
